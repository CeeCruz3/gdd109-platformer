# gdd109-endless-runner



First DrAft(SH) is a simple endless runner where you play as a drawn guy, trying to make it as far as you can with the world being "drawn in" (generated) as you progress.

The current plan is to get the backbone of the project working, then encode collectables properly. The visual elements of the game will be worked on near last, though I will work on geting ED's animations throughout next week, as well as Light pickups.
Most assets will be made by me, though I am unsure how well that'd pan out. Difficulty will be determined by time, and some obstacle patterns will be added as the difficulty progresses.
